# 校园网自动认证脚本

本脚本用于自动检测校园网 Portal 认证状态，并在未登录时自动完成认证流程。支持从环境变量读取配置，提供详细的调试日志和明确的退出状态码，便于集成到自动化任务中。

## 文件说明

```
.
├── requirements.txt      # Python 依赖列表
└── wlan_login.py         # 主脚本
```

## 功能特性

- 自动检测外网连通性（通过访问 `baidu.com` 并检查返回内容）
- 检测网关（`1.2.3.4`）是否在线
- 从网关获取认证参数（支持 302 重定向和 XML 解析）
- 构造 Portal 登录请求（支持账号后缀、Base64 密码、动态 IPv6）
- 提供详细的调试日志（通过 `DEBUG` 开关）
- 返回标准退出状态码，便于脚本调用判断执行结果

## 安装依赖

```bash
pip install -r requirements.txt
```

或手动安装：

```bash
pip install requests python-dotenv
```

## 配置说明

脚本从当前目录下的 `.env` 文件读取配置。请创建 `.env` 文件并填入以下内容：

```env
# 认证账号（必填）
USERNAME=your_username
PASSWORD=your_password

# 账号后缀（根据运营商/渠道设置，例如 @cmcc、@telecom 或留空）
ACCOUNT_SUFFIX=@cmcc

# 调试模式（true/false）
DEBUG=true

# 手动指定 IPv6 地址（留空则自动获取本机全局 IPv6）
IPV6_ADDRESS=
```

### 参数说明

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `USERNAME` | 上网账号 | 无（必填） |
| `PASSWORD` | 上网密码（明文） | 无（必填） |
| `ACCOUNT_SUFFIX` | 账号后缀（如 `@cmcc`） | `@cmcc` |
| `DEBUG` | 是否输出详细调试信息 | `false` |
| `IPV6_ADDRESS` | 手动指定 IPv6（如 `2001:...`），留空则自动获取 | 空（自动获取） |

## 使用方法

运行脚本：

```bash
python wlan_login.py
```

脚本会自动执行以下步骤：
1. 检查外网是否已连通（若已连通则直接退出，返回码 0）
2. 检查网关是否可达（若不可达则退出，返回码 1）
3. 获取认证参数（若解析失败则退出，返回码 2）
4. 发送登录请求（若请求失败则退出，返回码 3）
5. 根据响应判断认证是否成功（若失败则退出，返回码 4）
6. 等待 3 秒后再次检测外网，确认最终状态（若仍未连通则退出，返回码 5）

## 退出状态码

| 状态码 | 含义 |
|--------|------|
| 0 | 执行成功（已在线或登录成功） |
| 1 | 网络异常（外网和网关均不可达） |
| 2 | 获取网关参数失败（解析错误） |
| 3 | 登录请求发送失败（网络错误或超时） |
| 4 | 认证失败（账号密码错误或参数不匹配） |
| 5 | 登录后外网仍未连通（可能未生效，需人工检查） |

## 注意事项

- 脚本依赖 Python 3.6 及以上版本。
- 确保网络环境能访问 `1.2.3.4`（网关）和 `10.0.1.5:801`（认证服务器）。
- 若 IPv6 自动获取的地址不符合认证要求，可在 `.env` 中手动指定。
- 调试信息包含完整请求 URL，方便排查问题。
- 本脚本仅适用于与示例相同的 Portal 认证系统（基于 WISPAccessGateway）。
